## 2. Production discipline (Jim's ledger — write the log before the state)
- **Manifest row before render**: date, slot, genre, source hash, voices, disclosure version,
  generating substrate. Append-only: `activity/YYMMDD/playlist-manifest.jsonl`.
- **Done = readback-verified** (live title/desc/privacy match manifest), never API-said-done.
- **Thin-day rule (sacred)**: a light day ships light and says so next morning. No padding,
  no backfill-and-pretend. Michael's amputation assay only reads true on an honest organism.
- **Quality gate**: Jim's provenance script (mechanical) **plus one human-judgment per day**
  (Iain's condition) — K's morning ear or a soul's honest no. Meaningful is a judgment;
  shipped is a transaction; both gates must pass.
